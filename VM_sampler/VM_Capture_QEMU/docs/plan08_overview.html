Plan 08 — The encoding floor

First analysis-stage plan: APF vs magnitude-weighted APF, the base-paper comparison. Pre-registration: EXPERIMENT_B1_ENCODING_FLOOR.md. Status: pipeline built, tested, and run on the real corpus; models pending.

The spine

Every earlier plan measured memory with one number per snapshot: the Active Page Fraction (APF) — the fraction of pages that changed. Plan 08 asks whether weighting each page by how much it changed buys anything. Weighted APF (wAPF) is the same reduction with one substitution:

armper snapshotmeasures
E0 · APF(1/N) Σ [h>0]breadth: how many pages moved
E1 · wAPF(1/N) Σ (h/32768)breadth & depth, as one number
E2 · pair(K/N, mean intensity)breadth & depth, kept apart

where h is per-page Hamming (bits flipped), N=262144 pages, K=changed pages. APF gives a changed page 1; wAPF gives it its graded amount. This is the thesis's baseline-grounded encoding comparison (R2) run for the first time — if the protocol can't work on the two simplest encodings, it can't be trusted on the complex one later.

The data already held the answer — no raw memory needed

The August campaign captured in substrate mode, so per-page Hamming (and cosine) already sit in the trajectory CSVs on the server. So APF and wAPF are a column-sum away, not a re-diff of 40 GB of raw dumps. One streaming pass per cell over the (up to 28 GB) CSV extracts both.

55 cells → 8971 windows, 19 workloads, 7 families. Extractor's derived APF verified IDENTICAL to the reference plan02_apf_helper. Data lives at ~/b1_out/<cell>/ on the server (source substrate CSVs at ~/memory_traces/queue_dir/). The raw chains are not on this server, so the fat substrate CSVs are the recompute backstop — keep them.

First real signal — the two arms reorder the workloads

Before any model, the per-workload means already show the arms are not redundant. The ratio wAPF/APF is the mean bits-changed per changed page.

workloadmean APFmean wAPFratio
mem_workingset_sweep0.2490.000140.0005
mem_writemag_sweep0.2520.003190.013
mem_random_write_pages0.2500.002080.008
app_sqlite_oltp0.0280.005100.18
app_json_parse0.0300.009360.31
app_compress_gzip0.0520.022180.42
The encodings disagree on the ranking. By APF, writemag (0.252) is ~5× more active than compress (0.052). By wAPF, compress (0.022) is ~7× more intense than writemag (0.0032) — a complete reversal. The mem/cache sweeps that dominate APF touch many pages one bit each (workingset writes 1 byte/page → ratio 0.0005); the app/compute workloads change fewer pages but rewrite them hard. wAPF is not a rescaling of APF — it changes what a simple learner can separate. That is the paper's point, visible before the first model.

The splits

Grouping is enforced (no cell or workload straddles a split). sandbox_stealth_paced is auto-flagged novelty under LOWO: it is the only workload in its family, so holding it out leaves nothing to train — expect recall ~0, by construction.

The instrument caught itself twice

Family mislabel. io_read_cache_hit was being filed under cache, not io — the family label did a loose substring match and "cache_" hides inside the name. It inflated cache to 777 windows and shrank io. Fixed to a first-token prefix; regression-guarded. Left unnoticed it would have corrupted the family ground truth.
Reps not grouping. The queue's run_matrix_testN_ prefix leaked into the workload label, so 55 cells read as 55 "workloads" (reps=1 each), breaking leave-one-rep-out. Fixed by deriving the canonical name from the source path.

Both are the project's own reflex: a gate that refuses bad data beats one that reports it. Three tests lock the load-bearing steps — extractor APF equals the reference, window values and 50% overlap are exact, splits never leak a group.

What's left

The plumbing is finished and trustworthy; the model that reads it is the only unbuilt piece. All of it runs twice — APF and wAPF — and the number that matters is the difference between the arms.

  • Phase 1 · AE bank next — one autoencoder per family, argmin reconstruction error → predicted family; then finer, per workload. Per-fold standardization fit on train only.
  • Phase 2 · single models — k-means, GMM, hierarchical (do families emerge unsupervised? judged by ARI/NMI vs a label-shuffle null), plus a random-forest supervised foil.
  • Later paper — the complex encoding (cosine restored, already stored in hc_field), spatial localization, and diffusion.
