- **2. shell env-var indirection** -- capture_producer_qemu_pmemsave.sh:21 CONFIG="${CONFIG:-$ROOT/config_qemu.json}" and the PRODUCER_SCRIPT/CONSUMER_SCRIPT defaults in run_qemu_capture.sh are edges to the DEFAULT target (binding interpolated). - **4. runtime alternatives** -- console_bridge.py:65 PRODUCER_SCRIPTS is consumed only by pkill -f (stop) and pgrep -f (health): process-name coupling, not a launch site. Both producers are drawn from the bridge as invokes with binding unresolved and alternative=true so the tuple is visible; the real launch chain is console_bridge -> (screen) run_files_controlled.py -> run_qemu_capture.sh -> producer, where the producer is an env-selected alternative (pmemsave default; capture_producer_qemu.sh and _user_raw.sh drawn alternative/unresolved).
