The whole experiment as a graph

Every entry before this one moved through a single pipe: two metrics into a complex number, into one analysis, into one model. That pipe turns out to be one path through something much larger — sixty-four built metric channels, four more only specified, and four tiers of composition to route them through. This entry is that graph, drawn in full.

The one idea to hold onto

A metric was never a primitive. It is a point in a small designed space — representation × reading × reference × unit — and the pipeline this whole diary has been describing is one traversal of a graph it did not know it was part of.

The reframe

One pipe becomes a graph of sixty-four

Hamming and Cosine, the two metrics behind every entry so far, were never irreducible. Each is four choices — a representation, a reading, a reference, and a unit — and changing any one of them produces a different, equally legitimate metric. Sixty-four such channels are already built, across four families; four more are specified but not yet captured. The 2025 pipeline picked exactly one route through that space and never saw the rest of it.

Which path wins is not yet answered

The figure's lit path is what actually ran. The grey ghost paths are built but never tried; the amber ones are specified but not yet captured. Toggling the validation gates shows the conditions each transition has to clear before its output can be trusted; toggling the rival path shows one concrete alternative route through the same graph.

What this entry is, and isn't

This is the map, not the answer. Which route through this graph actually separates the workloads is the open question the rest of the project is now aimed at.

The evidence

  1. Traced vs inferred. The metric counts (20 + 19 + 13 + 12 = 64) and the four unbuilt families were established in an earlier discovery pass over the project's metric-selection code and planning notes, not re-verified line-by-line for this entry.
  2. The graph framing is inferred. It restates a reframing worked out in conversation with the author — no single document states the pipeline as a graph. That reframing is this entry's contribution, not a citation.
